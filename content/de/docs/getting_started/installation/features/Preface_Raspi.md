## Bereiten Sie die SD-Karte mit dem Betriebssystem und dem Player für den Raspberry Pi vor:

**Wichtiger Hinweis:** Es gibt viele verschiedene Möglichkeiten, den COHI Player Mini auf einem Raspberry Pi zu betreiben. Sie können zwischen einem Raspberry Pi 4 oder 5 wählen und sich für verschiedene Arten von Displays entscheiden. Alle Installationen erfordern spezifische Konfigurationen und die Installation der richtigen Treiber. Da es so viele mögliche Kombinationen gibt, haben wir uns entschieden, nur einige wenige mit einem vorgefertigten Image zu unterstützen, das dann keine weiteren Anpassungen oder zusätzlichen Installationen erfordert. Die unterstützten Kombinationen sind

(1) Raspberry Pi 4 mit 3,5-Zoll-Display. Zwei Displays werden definitiv unterstützt: </br>
(a) offizieller Raspberry 3,5-Zoll-Touchscreen, Typ RPI-35LCD </br>
(b) 3,5-Zoll-Touchscreen für Raspberry Pi 4, 480 x 320 Pixel, 60 FPS, Mini-Monitor mit Stylus und Mini-Lüfter für Raspberry Pi 3/4/5, angeboten von CUQI </br>

(2) Raspberry Pi 5 mit offiziellem 7-Zoll-Display, Typ RPI-7LCD2

Wenn Sie Ihre Wahl getroffen haben, befolgen Sie diese Schritte:

**Erstellen Sie wie folgt eine neue SD-Karte für den Raspberry Pi:**

1. Stecken Sie eine neue SD-Karte (mindestens 16 GB) in den SD-Kartensteckplatz Ihres PCs (falls vorhanden) oder in einen an Ihren PC angeschlossenen SD-Kartenleser.
