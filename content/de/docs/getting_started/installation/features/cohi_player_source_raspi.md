### Alternative Installation direkt vom Source-Code

Alternativ können Sie statt des vorbereiteten Images auch eine individuelle Installation direkt vom [Source-Code auf GitHub](https://github.com/CPG-Archive/COHI-Player-Universal) durchführen. Dies kann interessant sein, wenn Sie auf Ihrem Raspberry Pi bereits ein geeignetes OS (Trixie) installiert haben bzw. lediglich ein Update der COHI-Player-Software machen möchten. Die Installationsschritte sind in der [README-Datei](https://github.com/CPG-Archive/COHI-Player-Universal/blob/master/README.md) im Abschnitt „Installation“ beschrieben. **Wichtig:** Die mitgelieferten C++-Tools (für die Stream-Betriebsarten und den fl2k) müssen immer auf dem Ziel-Raspberry-Pi selbst kompiliert werden.

**Bei speziellen Fragen zur Software für den Raspberry Pi wenden Sie sich bitte an Claus Peter Gallenmiller: [E-Mail](mailto:cpg-radio@gmx.de).**
