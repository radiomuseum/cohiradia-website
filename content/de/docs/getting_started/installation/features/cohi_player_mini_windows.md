## COHI-Player als Python-Version für Windows installieren

Sie können den COHI-Player aus dem [Quellcode auf GitHub](https://github.com/CPG-Archive/COHI-Player-Universal) installieren. Installieren Sie dazu Python 3 von [python.org](https://www.python.org/), laden Sie das Release herunter bzw. klonen Sie das Repository und führen Sie im Programmverzeichnis `pip install -r requirements.txt` aus. Details finden Sie im Abschnitt „Installation“ der [README-Datei](https://github.com/CPG-Archive/COHI-Player-Universal/blob/master/README.md).

**Einschränkung unter Windows:** Unter Windows steht nur die Betriebsart COHI-Player (Wiedergabe von IQ-Aufzeichnungen) zur Verfügung. Die Webradio-Stream-Betriebsarten (COHI-Stream, COHI-Player+Stream) benötigen C++-Tools, für die es keine Windows-Version gibt; dafür verwenden Sie bitte Linux oder einen Raspberry Pi.
