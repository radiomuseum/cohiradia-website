## Installation des Treibers für ADALM2000:

Um den ADALM2000 am PC zu betreiben, muss die libm2k installiert werden. [Unter dieser Seite](https://wiki.analog.com/university/tools/m2k/libm2k/libm2k#windows) findet man die entsprechenden Anleitungen für verschiedene Betriebssysteme.

Da die Option ADALM2000 außer durch das COHIRADIA-Team bis dato erst von einem Nutzer nachweislich getestet wurde, liegt nur begrenzte Erfahrung zu Problemen bei der Installation vor. Grundsätzlich konnten aber sowohl unter Windows10 als auch unter Debian 12/13 die Treiber erfolgreich installiert werden. Hier gibt es einen [ersten Testbericht](../../../documentation/Testberichte/ADALM2000.html) zur Performance.
