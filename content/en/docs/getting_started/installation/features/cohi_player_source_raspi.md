### Alternative installation directly from the source code

Instead of using the prepared image, you can also perform a custom installation directly from the [source code on GitHub](https://github.com/CPG-Archive/COHI-Player-Universal). This may be useful if you already have a suitable OS (Trixie) installed on your Raspberry Pi or if you simply want to update the COHI-Player software. The installation steps are described in the "Installation" section of the [README file](https://github.com/CPG-Archive/COHI-Player-Universal/blob/master/README.md). **Important:** the included C++ tools (needed for the stream modes and the fl2k) must always be compiled on the target Raspberry Pi itself.

**For special questions concerning the software for Raspberry Pi please contact Claus Peter Gallenmiller [email](mailto:cpg-radio@gmx.de).**
