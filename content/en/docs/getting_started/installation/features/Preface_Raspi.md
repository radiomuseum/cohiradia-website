## Important note:

There are many different possibilities to run the COHI Player Mini on a Raspberry Pi. You can chose between a Raspbery Pi 4 or 5 and you can opt for different types of displays. All installations require specific configurations and the installation of the correct drivers. As there are so many possible combinations, we decided to support just very few with a pre-prepared image, which then needs no further adaptations or addidional installations. The supported combinations are

(1) Raspberry Pi 4 with 3.5" display. Two displays are definitely supported: </br>
(a) official Raspberry 3.5" Touchscreen, type RPI-35LCD </br>
(b) 3.5" Touchscreen for Raspberry Pi 4, 480 x 320 Pixel 60 FPS Mini Monitor with Stylus and  Mini-ventilator for Raspberry Pi 3/4/5, offered by CUQI </br>

(2) Pi 5 with official 7" Display, type RPI-7LCD2
