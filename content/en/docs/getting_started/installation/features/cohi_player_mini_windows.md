## Install the COHI-Player as Python Version for Windows

You can install the COHI-Player from the [source code on GitHub](https://github.com/CPG-Archive/COHI-Player-Universal). To do so, install Python 3 from [python.org](https://www.python.org/), download the release or clone the repository, and run `pip install -r requirements.txt` in the program directory. Details can be found in the "Installation" section of the [README file](https://github.com/CPG-Archive/COHI-Player-Universal/blob/master/README.md).

**Limitation under Windows:** Under Windows only the COHI-Player mode (playback of IQ recordings) is available. The internet radio stream modes (COHI-Stream, COHI-Player+Stream) require C++ tools for which no Windows build is provided; please use Linux or a Raspberry Pi for these.
