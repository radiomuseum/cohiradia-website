### Prepare the SD card with the OS for the Raspberry Pi:

There are many different possibilities to run the COHIWizard on a Raspberry Pi. Currently we only support the Raspberry Pi 5, as the Pi 4 does not provide enough resources for stable performance. There are many different types of displays on the market which require specific configurations and the installation of the correct drivers. On our pre-prepared image we directly only support the official 7" Display, type RPI-7LCD2. This then needs no further adaptations or additional installations. Should you opt for another display type, then please install the required drivers manually.

**Please note:** The pre-prepared image contains the operating system and the COHI-Player, but **not the COHIWizard**. It will be installed afterwards directly on the Raspberry Pi.

**Create a new SD card  for the Raspberry Pi as follows:**

1. Insert a new SD card (at least 16 GB) into the SD card slot of your PC (if available) or into an SD card reader connected to your PC.
